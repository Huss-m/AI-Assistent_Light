# AI-Assistant Light

En webapp för att visa Gmail och Kalender-data.

## Installation

```bash
cd ai-assistant-light
.\venv\Scripts\activate
pip install -r requirements.txt
```

## Kör lokalt

```bash
uvicorn src.web.app:app --reload --host 0.0.0.0 --port 8000
```
